# Creative angles

Angles replace the former audience profile/persona model. They diversify the message and execution instead of over-segmenting Meta targeting.

| Field | Purpose |
|---|---|
| Name | Short internal label |
| Hook | Advertising opener |
| Awareness level | `unaware`, `problem_aware`, `solution_aware`, `product_aware`, `most_aware` |
| Visual style | `ugc`, `studio`, `lifestyle`, `text_heavy`, `before_after`, `demo` |
| Copy direction | Recommended tone, benefit and CTA |

From `/brand-setup`, review the research summary, choose a language and generate ten angles. Angle generation does not consume image credits. Angles can also be added, edited and deleted manually.

Easy Mode can inject one angle. Pro Mode can combine several angles as a batch dimension. The API, SDK, CLI and MCP use `list_angles`, `get_angle` and `generate_angles`; legacy `profiles` actions are not part of the current contract.
